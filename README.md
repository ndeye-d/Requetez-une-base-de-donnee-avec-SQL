# 📊Requeter une base de donnee avec SQL
## 🎯Objectif
Le but de ce projet est de faire une analyse du marché des assurances habitation française à l'aide de requêtes **SQL**
<img width="807" height="616" alt="image" src="https://github.com/user-attachments/assets/d4e95859-6bf2-45ae-8013-f6340c2a073a" />

## 🛠️Outils
- **SQLLite** : Stockage des données
- **SQL** : Interrogation de la base de données

## 🚀Résultats
Les contrats d'habitation sont majoritairement souscrit en **Ile-de-France** et sont plus chers dans cette région
